🎨 ColorCard Palette Database

Hierarchy: Style → Game → Category / Subcat / Type → Item. Every item ships six shading roles: Outline / Shade / Base / Light / Highlight / Shadow. Click a swatch to copy its HEX, or use the ColorCard extension inside Aseprite.

Data lives in extension/data/palettes/*.json (Style/Game/Category/Subcat/Type + six color roles). Add a new style or game simply by dropping in another JSON with the same structure.
